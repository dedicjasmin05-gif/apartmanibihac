# apartmanibihac.com

Grana `main` = WordPress dodatak **Apartmani Upiti** (deploy u `wp-content/plugins/apartmani-upiti`).

Upiti za smještaj s potvrdom vlasnika jednim klikom, kalendar s iCal uvozom (Booking/Airbnb) i izvozom, kapara, automatske poruke (BS/DE/EN).

Kratki kodovi na stranici objekta: `[abu_kalendar id="ID"]`, `[abu_upit id="ID"]`.
